# file-distill

Distill a local document into an Obsidian/CareerOS-style reusable knowledge note.

## Provenance

Derived from the third-party skill `file-distillation` by `shazamlll`
(upstream: https://github.com/shazamlll/file-distillation). This repository is a
renamed, locally adapted variant — `file-distillation` → `file-distll` → `file-distill`.

Credit and original license belong to the upstream authors. Changes here are limited to
the skill name/frontmatter and local output-path adaptation (distilled notes are written
to `~/薦家/布球/` in this environment rather than the upstream Windows path).

## Install

```bash
npx skills add phycomp/file-distill@file-distill -g -y
```

## Usage

Trigger on "提煉", "蒸餾", "distill", "condense", "extract reusable knowledge from a local document".
